WINDOWS · CHROME TO HELIUM

Bring your open tabs.

Add the helper to Chrome, save a launcher, then open it. Your Chrome tabs stay open.

1. Add the helper to Chrome

  1. Keep the Chrome windows you want to transfer open.
  2. In Chrome’s address bar, enter chrome://extensions.
  3. Turn on Developer mode, then click Load unpacked.
  4. Select the extracted folder containing manifest.json. In a source checkout, select extension.
  5. From Chrome’s extensions menu, pin Chrome Tabs to Helium.

If Chrome says the manifest is missing, select the folder where you can see manifest.json. Install this helper in Chrome only.

2. Save your tab launcher

Click the helper icon. Check the tab and window counts, then choose Save Helium launcher.

Save the .cmd file somewhere you can find it. Tabs are captured when you click Save.

Normal windows in the current Chrome profile are included. Incognito and Chrome settings pages are excluded. Repeat in other profiles if needed.

3. Open the tabs in Helium

Double-click the .cmd file you just saved. It detects Helium automatically. If asked, select Helium’s executable.

The usual location is %LOCALAPPDATA%\imput\Helium\Application\chrome.exe. The executable is named chrome.exe even though it belongs to Helium.

Each captured Chrome window opens as a new Helium window. Tab order and duplicates are kept.

Finish

Check your tabs in Helium, then delete the launcher and remove the helper from Chrome if you no longer need it.

Only run launchers you made with this helper. The file contains private URLs and executable code. It transfers links; websites may ask you to sign in again.

This is a local, optional migration helper. It does not install extensions automatically, change browser settings, or copy authentication. Flow details · Script model
